# DepGuard — Store Description (ASO-Optimized)

## Full Description

**DepGuard — Security scans that actually make sense. Local. Fast. MCP-ready.**

Stop staring at raw `npm audit` JSON output. DepGuard brings vulnerability scanning into VS Code with a clean, color-coded panel — critical in red, high in orange, medium in yellow, low in blue. Everything runs locally. Your code never leaves your disk.

### What You Get (Free Tier)

- **One-click scan** — runs `npm audit` locally in seconds
- **Color-coded severity panel** — instantly see what matters
- **Expandable CVE details** — click any vulnerability for advisory link and fix recommendation
- **Export HTML report** — ready to paste into PR descriptions or Slack threads

### Pro — $9 One-Time

Unlock the full power:

- **[Phase 2 - Upcoming] PDF report export** — professional-looking reports for compliance docs
- **[Phase 2 - Upcoming] AI fix explanations** — describe each vulnerability in plain English via your own OpenAI / Claude / Gemini key
- **[Phase 2 - Upcoming] MCP Server mode** — expose `scan-project`, `show-fix-command`, and `export-report` tools so Claude Code, Cursor, and GitHub Copilot CLI can trigger scans for you
- **[Phase 2 - Upcoming] Auto-refresh** — re-scan automatically when `package-lock.json` changes

### Why DepGuard?

| vs. `npm audit` | vs. Snyk |
|---|---|
| Readable panel instead of raw JSON | Zero cloud dependency — runs locally |
| Severity badges at a glance | No accounts, no sign-up, no project uploads |
| One-click HTML export | Paste-ready for CI and PR descriptions |
| Future MCP/Agent support | Privacy-first: your code stays yours |
