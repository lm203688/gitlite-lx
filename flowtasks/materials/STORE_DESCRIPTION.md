# FlowTasks — Store Description (ASO-Optimized)

## Full Description

**FlowTasks — Describe your workflow. Build, run, repeat. All local.**

Stop manually editing `tasks.json` every time you switch projects. FlowTasks lets you define reusable **task groups** — sequences of shell commands — and execute them all with one click, right inside VS Code's integrated terminal. Nothing leaves your machine.

### What You Get (Free Tier)

- **Create task groups** with a simple GUI (no JSON editing)
- **Add as many steps as you like** to each group (`npm install`, `npm run build`, `pytest`, etc.)
- **One-click execution** — runs steps sequentially in the terminal
- **Up to 5 groups** — enough for most personal projects

### Pro — $9 One-Time

Unlock the full power:

- **Unlimited task groups** — organize by project, environment, or purpose
- **[Phase 2 - Upcoming] AI-assisted generation** — describe your workflow in plain English, let OpenAI / Claude / Gemini generate the step list (your own API key, never ours)
- **[Phase 2 - Upcoming] MCP Server mode** — expose your task groups to Claude Code, Cursor, and GitHub Copilot CLI so AI agents can run them for you
- **[Phase 2 - Upcoming] Execution history** — track what ran when, success or failure
- **Batch execute** — run all groups in order with a single command

### Why FlowTasks?

| vs. Built-in Tasks | vs. Cloud Runners |
|---|---|
| Visual GUI instead of manual JSON | Zero cloud dependency — runs locally |
| Cross-project reusable groups | No accounts, no sign-up |
| One-click batch execution | Paste-ready for CI pipelines |
| Future MCP/Agent support | Privacy-first: your code stays yours |
