FlowTasks Privacy Policy

Last updated: 2026-11-23

1. What we collect

FlowTasks does not collect any personal data or usage telemetry. All task definitions, step commands, and execution history are stored locally on your machine inside VS Code's globalState.

The only network call that leaves your machine occurs when you activate a Pro license key against our verification endpoint (snapmark-license.463102527.workers.dev). This transmits only the license key string (a short alphanumeric token). Our Cloudflare Worker backend validates it against KV storage and returns a boolean. No other data is sent.

If you use the optional AI task-generation feature (Pro, Phase 2), your API key is stored locally and used exclusively for direct HTTPS calls to your chosen AI provider (OpenAI / Claude / Gemini). We never intercept, log, or store your API key or the content you send to it.

2. What data we store

All local data lives in VS Code's globalState:

  • Task groups — name, list of shell steps, creation/update timestamps.
  • Execution history — group name, timestamp, success/failure flag (last 100 entries).
  • Pro flag + license key — stored locally; the key is also submitted to the verification endpoint during activation.

We do not create any files outside VS Code's standard data directories, and we never upload task definitions, command output, or working-tree content anywhere.

3. Third-party services

  • Paddle Billing — processes payment for the Pro upgrade. See the Paddle Privacy Policy.
  • Cloudflare Workers + KV — hosts the license verification API at snapmark-license.463102527.workers.dev. Cloudflare's standard logging applies to this endpoint. License keys are stored in Cloudflare KV (marked expired on cancellation, not deleted).
  • Your chosen AI provider (OpenAI / Anthropic / Google) — only contacted directly by your browser/VS Code when you explicitly configure an API key. We do not proxy or observe these requests.

There is no third-party analytics, advertising, or tracking within FlowTasks.

4. Data retention

Since no user data leaves your machine, there is nothing for us to retain. The license verification log may contain the timestamp of your last request; this is not linked to your identity and is used solely for operational monitoring.

5. Your rights

You may revoke your Pro license at any time through the Paddle customer portal. Upon cancellation, your local task groups and settings remain on your machine; only the Pro flag is cleared from our KV store.

6. Contact

For privacy-related questions, email privacy@lxstudio.dev.

7. Changes

We may update this policy. Continued use after changes constitutes acceptance of the new terms.
